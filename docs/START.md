# SjåførProf Vestland

Dette er en første komplett prosjektstruktur for en buss- og togapp som er tilpasset Vestland.

## Start prosjektet

1. Installer root dependencies:
```bash
npm install
```

2. Installer frontend og backend dependencies:
```bash
cd frontend && npm install
cd ../backend && npm install
```

3. Start backend:
```bash
cd backend && npm run dev
```

4. Start frontend:
```bash
cd frontend && npm run dev
```

5. Åpne i nettleser:
```text
http://localhost:5173
```

## Bemerk

Dette er en fungerende base som er klar til å utvides med ekte skyss/entur/Bane Nord integrasjoner og native Android/iOS bygg med Capacitor.
